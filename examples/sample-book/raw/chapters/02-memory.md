## Memory needs structure

Memory improves when notes preserve the relationship between a claim and its evidence. A summary without a source location becomes difficult to revisit.

The author writes, "a useful note keeps the path back to the passage". This chapter extends the first chapter's attention practice into a durable record.

## A compact record

A compact record names the chapter, the line range, and the unresolved question. It should not duplicate the entire source passage.
